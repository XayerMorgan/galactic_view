# Contributing to Astronautica

Open an issue describing the problem or proposed change, then send a pull
request against `main`. Include clear reproduction steps and screenshots for
interface problems. Avoid posting personal location data or unreviewed logs.

See [the build guide](docs/BUILDING.md) for the Unity version, packaging and
verification. Run the native regression suite for changes to coordinates,
navigation, audio, gallery behavior or release packaging. Include the relevant
test result in your pull request.

Keep the interface original and readable, with a visible horizon in the
observatory. Distinguish illustrative artwork from telescope photographs, and
scientific approximations from precision guidance. Preserve per-image credits
and dataset licensing. New assets need a source, author and usable license.

By contributing original code or documentation, you agree to license it under
the project's MIT license. Third-party material must retain its own terms.
