# Astronautica 1.0.0

The first packaged Windows release of Astronautica / Cosmic Explorer.

- Four cosmic scales with an original survey console and guided tour.
- Observatory with a local horizon, compass navigation, observer presets/custom
  coordinates and live approximate altitude/azimuth.
- Offline telescope gallery: all 110 Messier objects plus 12 deep-sky highlights,
  with search, sky targeting, individual credits and source/usage links.
- Nine instrumental selections with shuffle, pause, crossfades and volume;
  five new three-minute ambient pieces created through Magnific / ElevenLabs.
- Offline illustrated field guide via **F1**, **Settings → Help & field guide**,
  or the installed Start menu shortcut. Windows may ask which browser should
  open local HTML files if no file association has been selected.

## Downloads

Use **Astronautica-1.0.0-Windows-x64-Setup.exe** for a per-user installation with
shortcuts and an uninstaller. Administrator access is not needed. Alternatively,
extract the complete **Portable.zip** and run `CosmicZoomEngine.exe`.
Windows 10 21H1+ or Windows 11 x64; DirectX 11-capable graphics. The installer
is unsigned. **SHA256SUMS.txt** records both package hashes.

## Validation and scope

730 native player checks passed. 844 installer checks passed, covering clean
installation, all payload hashes, Start menu entries, reinstallation, uninstall
and preservation of user-owned files. All 416 portable payload hashes match;
122 photographs and 122 thumbnails are included. Gitleaks found no secrets in
the Git history or the source export. The guide was visually reviewed, its local
links checked, and the help button inspected at 1280×720; F1 also dispatches help
while the gallery is open.

The Local Group model contains only Milky Way and Andromeda. Sky positions are
approximate and are not precision telescope guidance. Cosmic distances, travel
times and body sizes are educational comparisons with the limitations described
in the guide. Artwork and generated audio are separate from telescope imagery.
