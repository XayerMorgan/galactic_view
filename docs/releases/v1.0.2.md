# Astronautica 1.0.2

Added **San Marcos, TX** to the built-in observer locations. In the app, open
**Observatory [S] → Sky → Change observer location → San Marcos, TX**.
Selecting it updates the local horizon and object altitude/azimuth, and the
existing observer preference keeps your selection between sessions.

The preset uses an approximate city reference point, 29.8736° north and
97.9367° west, from the
[U.S. Census TIGERweb Texas places table](https://tigerweb.geo.census.gov/tigerwebmain/Files/acs26/tigerweb_acs26_incplace_2026_bas26_tx.html).
Custom coordinates remain available for a particular observing site.

Install **Astronautica-1.0.2-Windows-x64-Setup.exe** over the previous version,
or extract the entire **Astronautica-1.0.2-Windows-x64-Portable.zip** into a new
folder. Package checksums are included in **SHA256SUMS.txt**.

Validation: 745 native player checks and 844 installer checks passed. All 416
portable payload hashes matched. Manual testing at 1280×720 confirmed the
San Marcos preset is visible, selection updates the local sky, and the selection
survives restarting the application. The previous observer selection was restored
after verification.
